# 遙測與空間資訊分析：ARIA v8.0 土地覆蓋分類專案報告

**課程名稱：** 台大遙測與空間資訊之分析與應用
**研究區域：** 2024 花蓮大地震後 — 秀林 / 太魯閣研究區 (Xiulin / Taroko)
**分析工具：** ARIA v8.0 — The Classification Engine
**主要方法：** K-means 非監督式分類、Random Forest 監督式分類、SWCB 官方圖資獨立驗證

---

## 1. 專案概述 (Project Overview)
本專案旨在將 ARIA 系統從 v7.0（單一閾值分析）升級至 **v8.0 — 分類引擎**。相較於過去僅能偵測「變化」，v8.0 引入了機器學習分類器，能夠同時處理多個波段的光譜資訊，將災後的衛星影像自動分類為水體、森林、農田、裸地/崩塌及建物等五大地物類別。

本次實作特別針對 2024 年 4 月 3 日花蓮地震後的太魯閣山區進行分析。該區域地形複雜且具備大量新生崩塌，是測試分類器效能的極佳場域。

---

## 2. 實作流程與調整紀錄

### Task 1: K-means 非監督式分類
* **方法：** 使用 `scikit-learn` 對 Sentinel-2 六個波段進行 $K=5$ 的分群。
* **調整紀錄：**
    * 由於機器分出的 Cluster ID (0-4) 與真實地物無直接關聯，我們透過計算各群集的**平均光譜反射率**進行判讀。
    * **修正對應關係：** 發現 Cluster 4 在 NIR/SWIR 波段反射率極低，判定為水體；Cluster 0 的 NIR 顯著飆高，判定為森林；Cluster 1 在 SWIR 波段反射率強，判定為裸地/崩塌。

### Task 2: Random Forest 監督式分類
* **方法：** 透過手動選取的 ROI (Region of Interest) 樣本訓練隨機森林模型。
* **調整紀錄：**
    * 研究區由平原（Hualien City）切換至山區（Taroko），重新在 Google Earth 描繪樣本。
    * **Side-by-Side 比較：** 為了公平比較 K-means 與 RF，我們對 K-means 的標籤進行了重新對應 (Re-assignment)，使其配色與圖例與 RF 完全一致。

### Task 3: 精度評估與官方圖資驗證
* **內部指標：** 整體準確度 (OA) 達 **98.3%**，Cohen's Kappa 展現極佳的一致性。
* **外部驗證 (SWCB)：** 引入水保署「20240802新生崩塌地.kml」進行獨立驗證。
    * **遇到問題：** KML 檔案命名空間 (`http://www.opengis.net/kml/2.2`) 導致讀取錯誤。
    * **修正方案：** 改用 `geopandas` 搭配 `fiona` 驅動程式穩定讀取向量資料。
    * **驗證結果：** IoU 為 **0.005**。反映了「光譜裸地」與「專家定義崩塌」之間的顯著空間差異。

### AI 診斷評估與修正 (Critical Evaluation)
* **數據準確性：** 經人工核對，AI 報告中引用的面積數據與 CSV 產出完全吻合，無幻覺現象。
* **不確定性說明：** AI 合理地解釋了 IoU 偏低的原因（光譜特性 vs. 空間脈絡差異），診斷紀錄具備高度專業參考價值。
* **修改建議：** 原始 AI 報告缺乏對「地形陰影」造成漏抓 (FN) 的討論。在最終修正中，我加入了針對山區陰影影響光譜辨識的技術說明。

## 4. 結語：從閾值到分類器的進階
從 v7.0 升級到 v8.0，我們不再受限於單一指標（如 NDVI），而是能利用全光譜資訊區分地物。儘管在崩塌地的精確定義上仍面臨挑戰，但 ARIA v8.0 提供的分類矩陣已能為災後資源分配提供數據化的基礎。
